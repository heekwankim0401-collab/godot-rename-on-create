# Rename on Create

Godot 4용 작은 에디터 플러그인입니다. **새 노드 만들기**(Create New Node) 창으로
노드를 만들면, 씬 독이 그 노드의 이름 편집을 바로 엽니다. <kbd>F2</kbd>나
<kbd>Enter</kbd>를 먼저 누르지 않고 곧바로 이름을 칠 수 있습니다.

[godot-proposals#2850](https://github.com/godotengine/godot-proposals/issues/2850)
("새 노드를 만들면 자동으로 이름 변경 선택")을 애드온으로 구현했습니다. 이 제안은
[godot#49521](https://github.com/godotengine/godot/pull/49521)과 기존
<kbd>Enter</kbd>/<kbd>F2</kbd> 단축키로 충분하다는 이유로 닫혔습니다. 하지만 토론에서
여러 사람이 이 동작을 원하는 사람만 켜는 선택 기능으로 요청했습니다. 이 플러그인을
설치하는 것이 바로 그 선택입니다.

## 설치

1. `addons/rename_on_create/` 폴더를 내 프로젝트의 `addons/` 폴더에 복사합니다.
2. **프로젝트 > 프로젝트 설정 > 플러그인**에서 **Rename on Create**를 켭니다.

`EditorInterface` 싱글톤을 쓰기 때문에 **Godot 4.2 이상**이 필요합니다. 실제로 시험한
버전은 [호환성](#호환성)을 보세요.

### 공식 에셋 배포처에서 설치

Rename on Create는 공식 배포처 두 곳에서도 받을 수 있습니다.

- [Godot 에셋 스토어](https://store.godotengine.org/asset/khkhk/rename-on-create/):
  Godot 4.7 이상 에디터의 Asset Store 탭에서 보입니다.
- [Godot 에셋 라이브러리](https://godotengine.org/asset-library/asset/5631):
  Godot 4.2~4.6 에디터의 AssetLib 탭에서 보입니다.

어느 쪽으로 받든 같은 `addons/rename_on_create/` 폴더가 설치됩니다. 설치한 뒤 위의 2번처럼
플러그인을 켭니다.

## 동작

새 노드 만들기 창이 노드를 만들 때 동작합니다. 이 창은 <kbd>Ctrl+A</kbd>, 씬 독의
**+** 버튼, 오른쪽 클릭 메뉴의 **자식 노드 추가**, 빈 씬의 **다른 노드** 버튼으로
엽니다. 창에서 노드를 고르고 확인하면 이렇게 됩니다.

- 새 노드가 씬 독에서 선택되고(원래 에디터 동작), 이름이 편집 상태로 열립니다.
  이름 글자는 전체 선택되어 있습니다.
- 바로 입력하면 이름이 바뀌고, <kbd>Enter</kbd>로 확정합니다.
- <kbd>Esc</kbd>를 누르면 기본 이름이 그대로 남습니다. 에디터의 다른 곳을 클릭하면
  칸에 있는 글자로 확정됩니다. 아무것도 입력하지 않았다면 기본 이름입니다.

이름 변경 자체는 <kbd>F2</kbd>로 시작하는 에디터 기본 이름 변경과 같습니다. 그래서
되돌리기/다시 실행과 이름 검사도 평소대로 동작합니다.

아래 경우에는 동작하지 **않습니다**.

| 작업 | 건너뛰는 이유 |
| --- | --- |
| 붙여넣기, 복제 | 만들기 창으로 새로 만든 노드가 아님 |
| 자식 씬 인스턴스, `.tscn` 끌어다 놓기 | 만들기 창이 아니라 씬 파일에서 옴 |
| 씬 열기, 씬 탭 바꾸기 | 아무것도 만들지 않음 |
| "노드 만들기" 되돌리기/다시 실행 | 만들기 창을 거치지 않음 |
| 유형 변경 | 기존 노드를 바꾸는 것 |
| 새 노드를 부모로 다시 지정(Godot 4.4 이상) | 끝나면 옮겨진 노드들이 다시 선택됨(한계 참고) |
| **2D 씬 / 3D 씬 / 사용자 인터페이스** 루트 버튼 | 이 버튼들은 만들기 창을 쓰지 않음 |

## 알려진 한계

- **노드를 만든 직후의 <kbd>Ctrl+A</kbd>.** 이름 편집 칸이 열려 있는 동안에는 다른
  글자 칸처럼 <kbd>Ctrl+A</kbd>가 글자 전체 선택이 됩니다. 새 노드 만들기 창이 다시
  열리지 않습니다. <kbd>Ctrl+A</kbd>를 여러 번 이어서 누르는 습관이 있다면, 매번
  <kbd>Enter</kbd>나 <kbd>Esc</kbd>를 먼저 누르세요. 제안 토론에서 가장 많이 나온
  반대 의견입니다.
- **루트 빠른 버튼은 지원하지 않습니다.** 2D 씬, 3D 씬, 사용자 인터페이스 버튼(그리고
  거기 보이는 즐겨찾기)은 만들기 창 없이 루트를 만듭니다. 그래서 플러그인이 다른 루트
  변경과 구별할 수 없습니다. 이 버튼을 쓴 뒤에는 <kbd>F2</kbd>나 <kbd>Enter</kbd>를
  누르세요. godot#49521 이후로는 씬 독에 이미 포커스가 있습니다. **다른 노드** 버튼은
  만들기 창을 쓰므로 지원합니다.
- **새 노드를 부모로 다시 지정은 Godot 버전에 따라 다릅니다.** 같은 만들기 창을
  쓰지만, 플러그인은 새 노드가 유일하게 선택된 노드일 때만 이름 변경을 엽니다.
  - Godot 4.4 이상에서는 끝난 뒤 에디터가 옮겨진 노드들을 선택하므로, 아무것도 이름
    변경 상태가 되지 않습니다.
  - Godot 4.2와 4.3에서는 새 부모가 선택된 채 남으므로, 새 부모의 이름 편집이
    열립니다.
- **사용자별 켜기/끄기가 없습니다.** 동작을 멈추려면 프로젝트 설정에서 플러그인을 끄세요.
- **씬 독이 보여야 합니다.** 다른 독 탭이 앞에 있으면 아무 일도 일어나지 않습니다.
  에디터 기본 이름 변경도 같은 규칙을 따릅니다.
- **에디터 내부 구조를 씁니다.** Godot에는 이 기능을 위한 공개 API가 없습니다.
  플러그인은 씬 독(`SceneTreeDock`)과 그 `node_created` 신호, 씬 독의
  `CreateDialog`와 그 `create` 신호, 씬 독의 `SceneTreeEditor` 안에 있는 `Tree`를
  찾아서 씁니다. 모두 내부 구조라서 나중 Godot 버전에서 바뀔 수 있습니다. 찾지 못하면
  경고를 출력하고 아무것도 하지 않습니다.

## 동작 원리

- 같은 호출 흐름에서 두 가지가 함께 일어날 때만 새로 만든 노드로 봅니다. 씬 독이
  `node_created`를 내보내고, 씬 독의 새 노드 만들기 창이 `create`를 내보내는
  경우입니다. 둘 중 하나만으로는 부족합니다.
  - 씬 인스턴스는 `node_created`를 내보냅니다. Godot 4.4부터는 다시 실행(Redo)도
    내보냅니다. 둘 다 만들기 창을 거치지 않습니다.
  - 유형 변경은 `create`는 내보내지만 `node_created`는 내보내지 않습니다.
  - 붙여넣기, 복제, 씬 열기는 둘 다 내보내지 않습니다.
- 두 신호는 어느 쪽이 먼저 올지 알 수 없습니다. 그래서 각 신호는 본 것만 기록하고,
  지연 호출 한 번이 판단합니다.
- 그다음 씬 독이 트리를 다시 그릴 때까지 몇 프레임 기다립니다. 새 노드가 유일하게
  선택된 항목이 되면 `Tree.grab_focus()`와 `Tree.edit_selected()`를 호출합니다.
  씬 독의 이름 변경 명령과 같은 호출입니다.

## 호환성

- **실제 에디터에서 시험함:** Godot 4.2.2, 4.6.3, 4.7.2 정식판(공식 빌드),
  Windows 11. 아래의 자동 테스트로 시험했고, 버전마다 검사 20개가 모두
  통과했습니다. 세 버전 모두 기본 여러 창 모드로 돌렸고, 4.7.2는 단일 창 모드로도
  돌렸습니다.
  - 여러 창 모드에서는 노드를 만들 때마다 이름 편집 칸의 창이 OS 키보드 포커스를
    가져갔습니다. 그래서 실제 키보드로 치는 글자도 그 칸으로 갑니다.
  - 키 입력은 테스트 플러그인이 직접 보냈습니다. 사람이 실제 키보드로 친 것은
    아닙니다.
- **소스만 확인함:** Godot 4.3, 4.4, 4.5도 같은 신호와 독 구조를 가지고 있습니다.
  하지만 그 버전에서 플러그인을 실제로 돌려 본 적은 아직 없습니다.

## 테스트 프로젝트

이 폴더는 플러그인이 이미 켜진 작은 Godot 프로젝트입니다. Godot 4로 이 폴더를 열고
`test/main.tscn`을 엽니다.

1. <kbd>Ctrl+A</kbd>를 누르고 노드를 고른 뒤 <kbd>Enter</kbd>를 누릅니다. 이름 편집
   칸이 열려야 합니다.
2. 붙여넣기, 복제(<kbd>Ctrl+D</kbd>), `test/instance_me.tscn` 인스턴스,
   되돌리기/다시 실행을 해 봅니다. 어느 경우에도 이름 편집 칸이 열리지 않아야 합니다.

### 자동 에디터 테스트

`addons/rename_on_create_test/`에는 [동작](#동작) 표의 모든 경우를 에디터에서 차례로
실행하는 별도의 에디터 플러그인이 있습니다. 애드온의 일부가 **아니므로** 내 프로젝트에
복사하지 마세요. 기본으로 꺼져 있습니다.

1. 프로젝트 설정 > 플러그인에서 **Rename on Create test runner**를 켭니다. 평소
   에디터를 쓸 때는 아무것도 하지 않습니다.
2. 이 폴더에서 `RT_OUT`을 설정하고 에디터를 실행합니다. 출력을 보려면 `_console`
   빌드를 씁니다.

   ```powershell
   $env:RT_OUT = "$PWD\test_results.txt"; & "C:\path\to\Godot_v4.7.2-stable_win64_console.exe" -e --path .
   ```

에디터가 열리고, 씬을 저장하지 않은 채 검사를 실행하고, `test_results.txt`를 쓴 뒤
종료합니다. 중간 단계가 깨져도 감시 타이머가 7분 뒤에 결과를 쓰고 종료합니다. 단일 창
모드를 시험하려면 명령에 `--single-window`를 붙입니다.

알아 둘 점:

- 테스트 플러그인은 실제 키보드를 거치지 않고 에디터 창에 키 입력을 직접 보냅니다.
  결과 줄마다 에디터 창이 OS 포커스를 가지고 있었는지 기록합니다.
- 여느 에디터 실행처럼 `.godot/` 폴더가 생깁니다. 테스트가 애드온을 껐다 켜기 때문에
  `project.godot`도 다시 저장됩니다.
- 테스트 플러그인은 오른쪽 클릭 메뉴 항목과 버튼을 에디터 아이콘으로 찾습니다. 그래서
  같은 파일이 Godot 4.2.2, 4.6.3, 4.7.2에서 모두 동작합니다.
