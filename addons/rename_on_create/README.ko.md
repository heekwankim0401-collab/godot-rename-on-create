# Rename on Create

**새 노드 만들기**(Create New Node) 창으로 노드를 만들면, 씬 독이 그 노드의 이름
편집을 바로 엽니다. 이름을 입력하고 <kbd>Enter</kbd>를 누르세요. <kbd>Esc</kbd>를
누르면 기본 이름이 남습니다.

**프로젝트 > 프로젝트 설정 > 플러그인**에서 켭니다. Godot 4.2 이상이 필요합니다.

붙여넣기, 복제, 씬 인스턴스, 되돌리기/다시 실행, 유형 변경, 새 노드를 부모로 다시
지정(Godot 4.4 이상), 2D 씬 / 3D 씬 / 사용자 인터페이스 루트 버튼에는 동작하지
않습니다. 이름 편집
칸이 열려 있는 동안 <kbd>Ctrl+A</kbd>는 새 노드 만들기 창을 다시 여는 대신 글자 전체
선택이 됩니다.
